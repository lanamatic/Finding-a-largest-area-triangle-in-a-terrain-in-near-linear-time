# Pronalaženje trougla najveće površine u terenu u skoro linearnom vremenu

Analiziran je problem pronalaženja trougla najveće površine koji je u potpunosti sadržan unutar terena, posebne klase x-monotonih poligona, iz oblasti računarske geometrije. Razmatra se rad Finding a largest-area triangle in a terrain in near-linear time, u kome je predstavljen deterministički algoritam skoro-linearne vremenske složenosti. Fokus rezimea je na formulaciji problema, ključnim strukturnim svojstvima optimalnog rešenja, osnovnim algoritamskim idejama i poređenju sa prethodnim rezultatima.
